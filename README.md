CreatorAI Backend V1

Run:
1. Install Node.js 18+.
2. Copy .env.example to .env.
3. Put your Gemini key in .env as GEMINI_API_KEY=...
4. Run: npm install
5. Run: npm start
6. Open http://localhost:3000/

POST /api/script JSON:
{"topic":"Indian bus games","language":"Telugu","type":"Shorts"}

Never upload .env or expose the API key in frontend JavaScript.
